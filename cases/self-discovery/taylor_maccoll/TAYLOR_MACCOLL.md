# Taylor-Maccoll 锥面绕流: 123框架迁移验证

## 目的

验证Guderley自发现PINN的123框架（化简 + 混合残差 + 硬约束）可以**迁移到完全不同的物理问题**。

## 问题描述

超音速气流绕锥体流动（Taylor-Maccoll conical flow）：
- 已知: 来流Mach数 M∞, 比热比 γ, 半锥角 θ_c
- 未知: 锥面激波角 β（eigenvalue）
- 传统方法: 打靶法（猜β → 积分TM ODE → 检查锥面切向条件）

## 框架迁移对照

| 框架组件 | Guderley | Taylor-Maccoll |
|---------|----------|----------------|
| **原始方程** | Euler PDE (球/柱对称) | Euler PDE (轴对称锥面) |
| **1. 化简** | → Chisnell ODE (V, C) | → TM ODE (θ, v_r, v_θ) |
| **2. 混合残差** | sonic点 (V-α)²=C | sonic线 c̃²=v_θ² |
| **3. 硬约束** | 激波端+音速端 (双端) | 激波端v_r + 锥面dv_r/dθ=0 |
| **eigenvalue** | α (自相似指数) | β (激波角) |
| **传统方法** | 打靶法+brentq | 打靶法+brentq |

### 化简 (Component 1)

Guderley: 3D Euler PDE → 自相似变换 → Chisnell 1st-order ODE for C(V)
Taylor-Maccoll: 3D axisymmetric Euler PDE → 锥面自相似 → TM 2nd-order ODE for v_r(θ)

### 混合残差 (Component 2)

TM ODE: v_r'' = N/D, 其中 D = c̃² - v_θ²

远离sonic线 (|D| >> 0): 除形式 v_r'' - N/D = 0, 梯度信号强
靠近sonic线 (|D| → 0): 乘形式 v_r''·D - N = 0, 避免除零

与Guderley的处理完全类比。

### 硬约束 (Component 3)

构造: v_r(s) = A + (B-A)·s² + s²(1-s)·net(s), s ∈ [0,1]
- s=0 (锥面): v_r(0) = A (learnable), dv_r/ds(0) = 0 ✓
- s=1 (激波): v_r(1) = B = v₁·cos(β) ✓

额外约束 (加项): 激波处v_θ匹配斜激波理论值 → 作为loss项

4/4 test cases全部收敛，β从粗糙初始猜测自发现到正确值。

### 与Guderley对比

| | Guderley 123 | Taylor-Maccoll 123 |
|---|-------------|-------------------|
| eigenvalue误差 | ~1e-6% | ~0.3-0.8% |
| ODE阶数 | 1阶 | 2阶 |
| learnable参数 | 1 (α) | 2 (β, v_rc) |
| 硬约束完整度 | 完美 (两端value) | 部分 (一端value + 一端derivative) |

精度差异的原因:
1. TM是**二阶ODE**, 需要二阶导数, autograd误差累积更大
2. **两个learnable参数**(β和v_rc), 优化landscape更复杂
3. 硬约束不如Guderley完美: 锥面端只约束dv_r/dθ=0(通过s²构造), 不像Guderley两端值都直接hard-code

### 关键观察

- **框架成功迁移**: 同一套recipe (化简→ODE, 混合残差, 硬约束+加项)直接适用
- **纯物理自发现**: β完全由ODE + 边界条件确定，零数据
- **0.3-0.8%精度**足以验证框架可迁移性; 精度可通过更多epochs/更好网络/自适应配点进一步提升
- **加项优势体现**: shock处v_θ匹配条件作为软约束loss项, 是打靶法框架中不存在的额外约束

## 意义

1. **同一框架，不同物理**: 123组件（化简+混合残差+硬约束）从Guderley直接迁移到Taylor-Maccoll，代码结构几乎不变
2. **纯物理自发现**: β完全由ODE + 边界条件确定，零数据
3. **打靶法的局限在此同样适用**: 需要bracket、需要处理sonic线、每次评估需要完整ODE积分

## 附录: 全部扩展实验总览与论文价值评估

### 扩展1: α+γ双参数反演（有数据）

- **问题**: α和γ都未知，同时反演
- **方法**: 123框架 + 观测数据loss + warmup冻γ
- **结果**: 4/4成功
- **性质**: 反演（需数据打破α-γ退化），不是自发现

### 扩展2: 参数化PINN α(γ)曲线（纯物理）

- **问题**: 一次训练发现γ∈[1.2,1.8]整条α(γ)曲线
- **方法**: α_net(γ)辅助网络 + 主网络C(s,γ)，纯ODE loss
- **结果**: α(1.4)误差0.015%，α(5/3)误差0.0004%
- **性质**: 纯自发现，零数据。但打靶法写个for循环也能做到

### 扩展3: 噪声鲁棒性（有数据）

- **问题**: 观测C(V)有1%/5%/10%高斯噪声，PINN能否鲁棒反演α
- **方法**: 123框架 + L_data = MSE(C_pred, C_obs_noisy)
- **结果**: 48/48全部成功，10%噪声下最大误差仅0.007%
- **性质**: 反演。证明"天然加loss项"的可扩展性，打靶法无法处理含噪数据

### 扩展4: 多几何统一自发现（纯物理）

- **问题**: 一个网络同时发现球面+柱面α，加ordering约束α_cyl > α_sph
- **结果**: work了，但ordering约束始终自然满足(violation=0)
- **性质**: 纯自发现，但物理太强，加项没被需要，**不能证明加项优势**

### 框架迁移: Taylor-Maccoll（纯物理）= 本文档

- **问题**: 超音速绕锥体，已知(M∞, γ, θ_c)，自发现激波角β
- **方法**: 同一套123框架直接迁移到完全不同的物理
- **结果**: 4/4成功，β误差0.3~0.8%
- **性质**: 纯自发现，零数据
