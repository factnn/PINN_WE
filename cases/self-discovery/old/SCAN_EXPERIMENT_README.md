# 漏斗扫描实验 - 实验说明

## 实验目的

这是一个**控制变量实验**，用于回答核心问题：

**当神经网络充分训练后，α=0.717处的损失是否真的最小？**

## 实验设计

### 测试的α值
```
[0.60, 0.65, 0.68, 0.70, 0.717, 0.73, 0.75, 0.80, 0.90, 1.00]
                            ↑
                        真实值
```

### 训练策略
对每个α值：
1. **完全重新初始化**神经网络（不继承权重）
2. **固定α**为常数（`requires_grad=False`）
3. **充分训练**：Adam(5000轮) + L-BFGS(2000轮)
4. **记录**最终损失

### 为什么这样做？

之前的实验中：
- α在变化
- 网络参数也在变化
- 两者混在一起，无法判断是网络没训练好，还是α真的有问题

现在：
- **只有网络参数在变化**
- α是固定的
- 可以清楚地看到"充分训练后，不同α值对应的最小损失"

## 预期结果

### 结果1：V型谷底 (SUCCESS) ✓

```
Final Loss
    |
    |  \     /
    |   \   /
    |    \ /
    |     X  ← α=0.717处最低
    |    / \
    +-----------> α
```

**说明**：
- α=0.717处损失确实最小（例如 10^-7）
- 其他α值损失更大（例如 10^-5）
- **结论**：物理方程正确，之前失败是优化策略问题

**下一步**：
- 使用贝叶斯优化
- 改进初始化策略
- 使用循环坐标下降

### 结果2：滑梯型 (FAILURE) ✗

```
Final Loss
    ||\
    || \
    ||  \
    ||   \___
    ||       ----___
    +-----------> α
```

**说明**：
- 损失随α增大而持续减小
- α=1.0处损失最小
- **结论**：损失函数形态与真实物理不符

**可能原因**：
1. PDE方程形式有误
2. 网络学到了平凡解（例如V→0, C→0）
3. 边界条件实现有问题

**下一步**：
- 检查PDE方程推导
- 添加正则化项惩罚平凡解
- 引入特征线变换
- 检查边界条件

这是**最扎实的诊断方法**：
1. 不依赖梯度信息
2. 不受优化路径影响
3. 直接测量损失函数的真实形状
4. 可以明确判断问题出在哪里

无论结果如何，都会给我们明确的方向：
- V型 → 改进优化策略
- 滑梯型 → 修正物理方程
