# Guderley 自相似指数自发现原理说明

## 1. 问题背景

### 1.1 物理问题
**Guderley 激波内爆问题**：强激波向球心汇聚，在接近中心时形成自相似解。

关键物理量：
- **自相似坐标**：ξ = r / R(t)，其中 R(t) ~ t^α
- **自相似指数**：α ≈ 0.717（未知，需要发现）
- **流场变量**：V(ξ) 速度，C(ξ) 声速，G(ξ) 密度

### 1.2 自发现目标
**不给定 α 的值，让神经网络从物理方程中"涌现"出 α = 0.717**

---

## 2. 网络结构

### 2.1 输入
- **输入维度**：1D
- **输入变量**：ξ（自相似坐标，范围 [0, 1]）
- **物理意义**：ξ=0 是球心，ξ=1 是激波位置

### 2.2 网络架构
```
输入层：ξ ∈ ℝ¹
    ↓
隐藏层 1：Linear(1 → 64) + Tanh
    ↓
隐藏层 2：Linear(64 → 64) + Tanh
    ↓
隐藏层 3：Linear(64 → 64) + Tanh
    ↓
隐藏层 4：Linear(64 → 64) + Tanh
    ↓
输出层：Linear(64 → 3)
    ↓
输出：[V_net, C_net, G_net] ∈ ℝ³
```

**激活函数**：Tanh（光滑，适合物理问题）

**参数量**：
- 隐藏层：4 层 × 64 神经元
- 总参数：约 17,000 个权重

### 2.3 可训练物理参数
**α（自相似指数）**：
- 初始化：α_init = 0.8（故意偏离真值 0.717）
- 约束范围：[0.5, 1.0]
- 存储方式：logit 空间 → sigmoid 映射到 [α_min, α_max]
- **这是核心待发现参数！**

## 3. 硬约束边界条件

### 3.1 边界条件（Rankine-Hugoniot 关系）
在激波位置 ξ=1 处，强激波理论给出：
```
V(1) = 2/(γ+1) = 0.833333
C(1) = √[2γ(γ-1)]/(γ+1) = 0.440959
G(1) = (γ+1)/(γ-1) = 6.0
```
其中 γ=1.4（空气的比热比）

### 3.2 硬约束实现
**关键思想**：将边界条件编码到网络输出中

```python
# 网络原始输出
V_net, C_net, G_net = Net(ξ)

# 硬约束变换
V = V_bc + (ξ - 1) × V_net
C = C_bc + (ξ - 1) × softplus(C_net)
G = G_bc + (ξ - 1) × softplus(G_net)
```

**数学性质**：
- 当 ξ=1 时：V=V_bc, C=C_bc, G=G_bc（自动满足边界条件）
- 当 ξ<1 时：网络学习内部结构
- **BC Loss 理论上为 0**（机器精度误差 ~10⁻¹³）

## 5. 物理方程（PDE）

### 5.1 Guderley 自相似 ODE 方程组
```
Δ · dV/dξ = N_V / ξ
Δ · dC/dξ = N_C / ξ
```

其中：
- **分母**：Δ = (V-1)² - C²
- **分子 N_V**：N_V = (V-1)[V(V-1)(V-1/α) - 2C²/γ] - nC²(V-1)/(γα)
- **分子 N_C**：N_C = C[(V-1)(V-1/α) - C²/γ] - nC/(γα)
- **参数**：γ=1.4（比热比），n=2（球形对称）

### 5.2 数值稳定性改写
为避免除法导致的数值问题，改写为：
```
残差形式：ξ · Δ · dV/dξ - N_V = 0
         ξ · Δ · dC/dξ - N_C = 0
```

### 5.3 自动微分
使用 PyTorch 自动微分计算导数：
```python
dV/dξ = autograd.grad(V, ξ, create_graph=True)
dC/dξ = autograd.grad(C, ξ, create_graph=True)
```

---

## 6. 损失函数

### 6.1 PDE 残差损失
```python
res_V = ξ · Δ · dV/dξ - N_V
res_C = ξ · Δ · dC/dξ - N_C

loss_pde_V = mean(res_V²)
loss_pde_C = mean(res_C²)
loss_pde = loss_pde_V + loss_pde_C
```

**物理意义**：衡量网络输出是否满足 Guderley 方程

### 6.2 边界条件损失（监控用）
```python
loss_bc_V = mean((V(1) - V_bc)²)
loss_bc_C = mean((C(1) - C_bc)²)
loss_bc_G = mean((G(1) - G_bc)²)
loss_bc = loss_bc_V + loss_bc_C + loss_bc_G
```

**硬约束模式下**：BC Loss ≈ 0（仅用于监控，不参与优化）

### 6.3 总损失
```python
# 硬约束模式
total_loss = weight_pde × loss_pde

# 旧版本（软约束）
# total_loss = weight_pde × loss_pde + weight_bc × loss_bc
```

**权重设置**：
- weight_pde = 1.0
- weight_bc = 0.0（硬约束下不参与优化）

## 7. 优化策略

### 7.1 两阶段优化

**阶段 1：Adam 优化器**
- 轮数：5000 epochs
- 学习率：lr = 1e-3
- 作用：快速探索参数空间

**阶段 2：L-BFGS 优化器**
- 迭代次数：500 次
- 学习率：lr = 1.0
- 作用：精细调优，收敛到局部最优

### 7.2 优化目标
同时优化：
1. **网络权重**（17,000 个参数）→ 拟合 V(ξ), C(ξ), G(ξ)
2. **物理参数 α**（1 个参数）→ 发现自相似指数

### 7.3 梯度流
```
total_loss = PDE_loss(V, C, G, α)
    ↓
∂loss/∂α → 更新 α
∂loss/∂weights → 更新网络权重
```

## 9. 当前问题

### 9.1 实验结果
**硬约束成功**：
- BC Loss = 2.89e-13 ≈ 0 ✓
- 边界条件完美满足 ✓

**α 发现失败**：
- 初始值：α = 0.800
- 训练后：α = 0.847（持续增大）
- 真实值：α = 0.717
- **方向错误！**

### 9.2 问题分析
即使消除了 BC Loss 的干扰，α 仍然走错方向，说明：

**∂(PDE_loss)/∂α < 0**

优化器认为"增大 α 可以降低 PDE 残差"，但这与物理真实相反。

### 9.3 可能原因
1. **采样范围不足**：[0.4, 1.0] 缺少靠近球心的信息
2. **PDE 方程数值问题**：分母 Δ 在声速线附近可能不稳定
3. **网络表达能力**：无法准确拟合真实自相似解
4. **梯度信号弱**：PDE 对 α 的敏感度不够
