## 1. 问题背景: 什么是Guderley收缩激波？

### 1.1 物理图像

想象一个球形(或柱形)激波，从外部向中心收缩——比如惯性约束聚变(ICF)中激光驱动的内爆激波。这类激波在接近中心时会自我加速，其运动轨迹遵循幂律:

$$R(t) \propto (t_c - t)^\alpha$$

其中 $t_c$ 是激波到达中心的时刻，$\alpha$ 是一个**未知的特征值(eigenvalue)**。$\alpha$ 的值不是事先给定的，而是由Euler方程组的自相似解**唯一确定**的——这就是"自发现(self-discovery)"的含义。

- $\alpha < 1$ 意味着激波在加速（越靠近中心越快）
- $\alpha$ 的具体值取决于两个物理参数: 比热比 $\gamma$ 和几何形状（球面/柱面）

### 1.2 为什么这个问题重要？

1. **基础物理**: Guderley (1942) 首次提出此问题，是可压缩流体力学中的经典自相似问题
2. **应用**: ICF内爆、超新星激波等
3. **数学结构**: 它是一个**eigenvalue边值问题**——不是去解一个已知的方程，而是要同时发现方程的一个参数和解本身

### 1.3 原始方程：球/柱对称可压缩Euler方程

Guderley问题的出发点是**可压缩无粘Euler方程**在球对称（$n=3$）或柱对称（$n=2$）下的形式。设 $r$ 为径向坐标，$u$ 为径向速度，$\rho$ 为密度，$p$ 为压力，$c = \sqrt{\gamma p / \rho}$ 为声速，则守恒方程为：

这三个方程本质上都在说同一件事：**某个物理量的变化 = 流入量 - 流出量**。

质量守恒：

$$\frac{\partial \rho}{\partial t} + \frac{\partial (\rho u)}{\partial r} + \frac{(n-1)\rho u}{r} = 0$$

- $\frac{\partial \rho}{\partial t}$：某一点的密度随时间的变化率
- $\frac{\partial (\rho u)}{\partial r}$：质量通量 $\rho u$ 沿径向的梯度（有多少质量流进来、流出去）
- $\frac{(n-1)\rho u}{r}$：**几何项**，球/柱坐标特有。想象一个膨胀的球壳，即使速度不变，面积在增大，质量会被"稀释"。$n=3$（球）时效应比 $n=2$（柱）更强，因为球面积增长更快

三项加起来等于零 = 质量不会凭空产生或消失。

动量守恒：

$$\frac{\partial (\rho u)}{\partial t} + \frac{\partial (\rho u^2 + p)}{\partial r} + \frac{(n-1)\rho u^2}{r} = 0$$

- $\frac{\partial (\rho u)}{\partial t}$：动量密度的时间变化
- $\frac{\partial (\rho u^2 + p)}{\partial r}$：两部分——$\rho u^2$ 是动量的对流输运（流体自己带着动量跑），$p$ 是压力梯度力（高压推低压）
- $\frac{(n-1)\rho u^2}{r}$：几何项

本质就是**牛顿第二定律** $F=ma$，写成流体的连续形式。

能量守恒：

$$\frac{\partial E}{\partial t} + \frac{\partial [(E+p)u]}{\partial r} + \frac{(n-1)(E+p)u}{r} = 0$$

其中 $E = \frac{p}{\gamma - 1} + \frac{1}{2}\rho u^2$，即总能量 = 内能（热）+ 动能。

- $(E+p)u$ 是能量通量。为什么是 $E+p$ 而不是 $E$？因为流体在流动时，压力会对周围做功（$p \cdot u$），这部分功也要算进能量输运里

本质就是**热力学第一定律**：能量不会凭空产生或消失。

其中 $n=3$ 对应球面，$n=2$ 对应柱面。这是一个**三方程三未知量（$\rho, u, p$）、两个自变量（$r, t$）的非线性双曲PDE系统**——直接求解非常困难。

### 1.4 天才的数学变换：从3D PDE到1个ODE

这里是整个问题最精妙的部分。通过**三步变换**，上面的三方程PDE系统被化简为**一个一阶ODE**。

**第一步：自相似假设（Guderley 1942）**

假设激波轨迹服从幂律 $R(t) = A(t_c - t)^\alpha$，引入自相似坐标：

$$\xi = \frac{r}{R(t)}$$

并假设流场变量具有自相似形式：

$$u(r,t) = \dot{R}(t) \cdot V(\xi), \quad c^2(r,t) = \dot{R}^2(t) \cdot C(\xi), \quad \rho(r,t) = \rho_0 \cdot G(\xi)$$

其中 $V, C, G$ 是仅依赖 $\xi$ 的无量纲函数。代入Euler方程后，**偏微分方程变为常微分方程**——三个关于 $\xi$ 的ODE。

**第二步：消元（Chisnell 1998）**

Chisnell的关键洞察：在三个ODE中，$G(\xi)$（密度）可以被代数消去。进一步，将自变量从 $\xi$ 换为 $V$，得到**一个关于 $C(V)$ 的一阶ODE**：

$$\frac{dC}{dV} = \frac{N(V, C; \alpha, \gamma, n)}{D(V, C; \alpha, \gamma, n)}$$

其中分子和分母的具体形式为：

$$\delta = (V - \alpha)^2 - C$$

$$Q = nV(V - \alpha) + \frac{2}{\gamma}(1-\alpha)(\alpha - V) - V(V-1)$$

$$N = C\left[2\delta\left(\alpha - V + \frac{1-\alpha}{\gamma}\right) + (\gamma-1)(\alpha-V)Q\right]$$

$$D = \delta\left(nV - \frac{2(1-\alpha)}{\gamma}\right)(\alpha - V) + (\alpha - V)^2 Q$$

**第三步：边界条件**

这个ODE需要两个边界条件，分别来自两端的物理约束：

*激波端*（$V = V_s$）：由Rankine-Hugoniot跳跃关系确定

$$V_s = \frac{2\alpha}{\gamma + 1}, \quad C_s = \frac{2\gamma(\gamma-1)\alpha^2}{(\gamma+1)^2}$$

*音速点*（$V = V_0$）：ODE的分母 $D \to 0$（奇点），正则性要求分子也同时趋于零，由此代数确定

$$C_0 = (V_0 - \alpha)^2$$

其中 $V_0$ 由一个关于 $\alpha, \gamma, n$ 的代数方程给出。

**变换的精妙之处**：

- 原始问题是3个PDE + 4个变量 + 2个自变量（$r, t$）
- 变换后是1个ODE + 1个变量 $C(V)$ + 1个自变量 $V$
- 问题的维度从根本上降低了，但**未知参数 $\alpha$ 被保留在方程中**
- 只有唯一正确的 $\alpha$ 能让ODE的解同时满足两端的边界条件——这就是eigenvalue的来源

**这个变换链本身就是经典流体力学中最优美的数学结构之一。** 而我们的PINN方法之所以"朴实"，恰恰是因为它不需要理解这些精妙的变换——它只需要最小化ODE残差，就能自动发现正确的 $\alpha$。传统方法需要数学家的天才洞察力来完成每一步化简；PINN只需要一个损失函数和梯度下降。

### 1.5 特征值问题的数学结构

通过上述变换，问题变为：**求 $\alpha$，使得ODE $dC/dV = N/D$ 在 $[V_s, V_0]$ 上的解同时满足两端的边界条件。**

- ODE中包含未知参数 $\alpha$
- 两个边界条件（激波处和音速点处）都是 $\alpha$ 的函数
- 只有**唯一正确的 $\alpha$** 能同时满足两端的条件

**打个比方**: 想象一根弹簧的两端分别固定在墙上，弹簧的振动频率不是任意的，只有特定的"本征频率"才能满足两端的约束。这里的 $\alpha$ 就是类似的"本征值"——ODE加上两端的物理约束，只允许唯一的 $\alpha$ 存在。

这和量子力学中求能量本征值的结构完全类似：猜一个能量E → 解薛定谔方程 → 检查边界条件是否满足 → 只有正确的E才行。

## 2. 传统方法 vs 我们的方法

### 2.1 传统方法: 打靶法 (Shooting Method)

打靶法是求解这类问题的经典数值方法:

```
1. 猜一个 α 值
2. 从激波端出发，数值积分ODE到音速点
3. 检查: 积分到达的值 = 理论要求的值？
4. 不满足 → 用二分法调整 α → 回到步骤1
```

**打靶法很好用，但有局限**:

| 局限 | 说明 |
|------|------|
| 需要搜索区间(bracket) | 必须事先知道 $\alpha$ 大致在哪个范围，需要专门的理论公式 |
| 必须处理奇点 | ODE在音速点有奇点(分母=0)，积分方向选错就会爆炸 |
| 只能求一个参数 | 如果 $\gamma$ 也未知，需要完全重构为2D求根 |
| 无法融合数据 | 如果有含噪声的实验观测，打靶法无法自然使用 |

### 2.2 我们的方法: PINN + 123框架

**PINN (Physics-Informed Neural Network)** 是一种用神经网络求解微分方程的方法。核心思想：

- 网络输出 = ODE的解
- 损失函数 = ODE残差（解代入方程后的不满足程度）
- 训练网络 = 最小化残差 = 让解越来越满足方程

对于eigenvalue问题，我们把 $\alpha$ 也作为网络的可训练参数:

```
网络参数 + α → 最小化(ODE残差) → 同时得到解和正确的α
```

## 3. 我们的123框架

### 组件1: ODE化简 (PDE → 相平面ODE)

**不让PINN直接解3D Euler方程**，而是先用Chisnell (1998)的理论将其化简为**一个一阶ODE**:

$$\frac{dC}{dV} = \frac{N(V, C, \alpha)}{D(V, C, \alpha)}$$

其中 $V$ 是速度，$C$ 是声速平方。

**为什么重要**: 网络从学2个函数$(V(\xi), C(\xi))$变为只学1个函数$C(V)$，优化空间从根本上缩小。

**实验证据**: 有化简 vs 无化简，loss差**5-6个量级** (1e-9 vs 1e-3)。

### 组件2: 混合残差 (处理奇点)

ODE在音速点 $V = \alpha$ 处有奇点（分母 $D \to 0$）。怎么计算残差？

| 形式 | 公式 | 问题 |
|------|------|------|
| 纯除法 | $R = \frac{dC}{dV} - N/D$ | 奇点处 $D \to 0$，除零爆炸 |
| 纯乘法 | $R = \frac{dC}{dV} \cdot D - N$ | 远离奇点 $D$ 很大，梯度不均匀 |
| **混合(我们的)** | 远离奇点用除法，靠近用乘法 | 两全其美 |

**实验证据**: 纯除法在无warmup时loss爆炸到 $10^{14}$；纯乘法误差4-10%。**只有混合残差在所有条件下都稳定。**

下图直观展示了混合残差策略的原理:

![混合残差策略示意](self_discover/ablation/output/fig_mixed_residual.png)

- (a) 分母D在奇点V=α处趋向零
- (b) 纯除法形式N/D在奇点处爆炸
- (c) 混合策略: 用权重函数在远场(除法)和近场(乘法)间平滑过渡

### 组件3: 双端硬约束 (锚定物理边界)

ODE两端的值由 $\alpha$ 唯一确定:
- 激波端: $C_s(\alpha)$ (Rankine-Hugoniot)
- 音速端: $C_0(\alpha)$ (正则性条件)

我们把这些**硬编码进网络结构**:

$$C(s) = (1-s) \cdot C_s(\alpha) + s \cdot C_0(\alpha) + s(1-s) \cdot \mathrm{net}(s)$$

三项分别是：激波端值 + 音速端值 + 网络修正量。

其中 $s \in [0,1]$ 是归一化坐标。这个设计保证:
- $s=0$ 时 $C = C_s(\alpha)$（精确满足激波条件）
- $s=1$ 时 $C = C_0(\alpha)$（精确满足音速点条件）
- 中间由网络学习

**关键**: $C_s$ 和 $C_0$ 都是 $\alpha$ 的可微函数，所以 $\alpha$ 的梯度**天然从物理约束中流过**。

**实验证据**: 有硬约束 vs 无硬约束，精度提升**5个量级** (1e-6% vs 0.5%)。

下图直观展示了硬约束构造的原理:

![硬约束构造示意](self_discover/ablation/output/fig_hard_constraint.png)

- (a) 线性插值部分，精确经过两端物理值
- (b) 修正项 s(1-s)·net(s) 在两端**精确为零**，不破坏端点条件
- (c) 最终解 = 线性插值 + 修正，端点条件**结构性保证**

### 组件4: Warmup (结论: 不需要)

训练分两阶段: 先冻结 $\alpha$ 让网络稳定，再放开 $\alpha$ 联合优化。

**实验结论**: 在有硬约束(组件3)的情况下，warmup**不需要**。123和1234精度完全相同。硬约束已经提供了足够强的物理锚点。

## 3.5 PINN具体实现细节

上面介绍了123框架的设计思想，这里给出具体的网络结构、训练配置和实现细节。

### 网络结构

| 项目 | 设置 |
|------|------|
| 网络类型 | 全连接MLP (Multi-Layer Perceptron) |
| 层数 | 5层 (3个隐藏层) |
| 每层神经元 | 64 |
| 激活函数 | Tanh |
| 输入维度 | 1 ($s \in [0,1]$，归一化坐标) |
| 输出维度 | 1 (网络修正量) |
| 数据精度 | float64 (双精度) |
| 总参数量 | ~8,500 (网络权重) + 1 ($\alpha$) |

网络很小——只有5层64神经元。这是因为我们只需要学一个1D函数 $C(s)$，不需要大网络。

### 输入与输出

网络的输入不是物理坐标 $V$，而是归一化坐标 $s$：

$$s = \frac{V - V_s}{V_0 - V_s} \in [0, 1]$$

其中 $V_s$（激波端）和 $V_0$（音速端）都是 $\alpha$ 的函数。网络输出经过硬约束变换后得到最终的 $C(V)$：

$$C(s) = (1-s) \cdot C_s(\alpha) + s \cdot C_0(\alpha) + s(1-s) \cdot \mathrm{net}(s)$$

网络实际只学习中间的修正量 $\mathrm{net}(s)$，两端的值由物理公式硬编码。

### 可训练参数 $\alpha$ 的参数化

$\alpha$ 不是直接作为参数优化的，而是通过sigmoid变换约束在物理合理的范围 $[0.5, 1.0]$：

$$\alpha = 0.5 + 0.5 \cdot \sigma(\alpha_{\rm raw})$$

其中 $\alpha_{\rm raw} \in (-\infty, +\infty)$ 是实际的可训练参数，$\sigma$ 是sigmoid函数。这样做的好处：
- $\alpha$ 永远不会跑出物理范围
- 梯度通过sigmoid自然流动，不需要手动clip

### 配点采样

| 项目 | 设置 |
|------|------|
| 配点数量 | 400 |
| 采样方式 | 均匀分布在 $s \in [0.01, 0.99]$ |
| 避开端点 | 是（避免 $s=0$ 和 $s=1$ 处的数值问题） |

配点在每个epoch是固定的（不随机重采样），因为问题是1D的，400个点已经足够密。

### 损失函数

总损失由两部分组成：

$$L = L_{\rm ODE} + 10 \cdot L_{\rm regularity}$$

其中：

$L_{\rm ODE}$：ODE残差，使用混合残差策略（组件2）

- 远离奇点（$|D| > 10^{-6}$）：除法形式 $\left(\frac{dC}{dV} - \frac{N}{D}\right)^2$
- 靠近奇点（$|D| \leq 10^{-6}$）：乘法形式 $\left(\frac{dC}{dV} \cdot D - N\right)^2$
- 两者之间用权重 $w = \mathrm{clamp}(|D|/10^{-6} - 1, 0, 1)$ 平滑过渡

$L_{\rm regularity}$：奇点正则性约束

- 在奇点附近额外要求分子 $N \to 0$（因为正则解要求分子分母同时趋于零）
- 权重系数10，比ODE残差更强调这个约束

### 优化器与训练策略

训练分两个阶段：

**阶段1: Warmup（前1/3 epoch）**

| 项目 | 设置 |
|------|------|
| $\alpha$ 状态 | 冻结（不更新） |
| 优化器 | Adam |
| 学习率 | $10^{-3}$ |
| 目的 | 让网络先学会一个合理的 $C(V)$ 形状 |

**阶段2: 联合优化（后2/3 epoch）**

| 项目 | 设置 |
|------|------|
| $\alpha$ 状态 | 解冻（参与优化） |
| 优化器 | Adam（分组学习率） |
| 网络学习率 | $3 \times 10^{-4}$ (原lr × 0.3) |
| $\alpha$ 学习率 | $2 \times 10^{-4}$ (原lr × 0.2) |
| 学习率调度 | CosineAnnealing，最小lr = $10^{-6}$ |
| 梯度裁剪 | max_norm = 1.0 |

$\alpha$ 的学习率比网络更小，因为 $\alpha$ 的变化会同时改变两端边界条件和ODE方程本身，影响面更大，需要更保守地更新。

### 默认训练配置

| 项目 | 设置 |
|------|------|
| 总epoch | 10,000 |
| warmup epoch | 3,333 |
| 联合训练epoch | 6,667 |
| $\alpha$ 初始猜测 | 0.75（或根据配置微调） |
| 训练时间 | ~2分钟 (CPU) |

**注意**: 消融实验证明，在有硬约束(组件3)的情况下，warmup阶段实际上不是必需的（123和1234精度相同）。但保留warmup不会有害，且在某些极端初始化下可能提供额外稳定性。

## 4. 消融实验: 证明每个组件的必要性

### 为什么要做消融实验？

上面说了123框架效果好（误差~$10^{-6}$%）。但读者和审稿人会问：
- **是不是只要随便用个PINN就行，123框架是过度设计(over-engineering)？**
- **3个组件是不是都有用？去掉一个会怎样？**

消融实验(ablation study)就是回答这个问题：**系统地去掉/替换每个组件，观察性能变化**。这是深度学习论文中证明方法有效性的标准方式。

我们一共做了**20+组对照实验、14种不同组合**，覆盖4种物理配置(2个γ × 2种几何)，共计50+次独立训练。

| 输出连续解 | 否 | 是 |

**预期质疑：所有物理信息都给了PINN，这还叫"自发现"吗？**

这是一个必须正面回应的问题。确实，我们的PINN框架使用了与打靶法**完全相同的物理信息**：ODE方程、Rankine-Hugoniot跳跃条件、音速点正则性条件。一个合理的质疑是：既然信息量一样，甚至不用神经网络，随便写一个 `scipy.minimize`（以 $\alpha$ 为变量、ODE残差为目标函数）也能找到正确的 $\alpha$——我们的 `canonical/nonpinn_fit.py` 就是这么做的，效果也不差。

我们的回应：

1. **Guderley不是目的，是benchmark。** 正因为它有12位精度的参考解，才能用来做严格的消融实验。本文的核心贡献不在于"用PINN解了Guderley"，而在于通过系统消融揭示的**设计原则**：对eigenvalue ODE问题，混合残差、硬约束是必要的，warmup不是。这些insight对后来人处理类似问题有直接指导意义。

2. **PINN的真正价值在打靶法做不到的场景。** 当问题变得"非标准"时——含噪观测数据（48/48成功）、多参数同时未知（$\alpha + \gamma$ 双反演）、迁移到不同物理（Taylor-Maccoll）——打靶法需要根本性的重构，而PINN只需修改loss函数。这些扩展实验才是PINN框架独特价值的体现。

3. **"自发现"的含义是 $\alpha$ 从梯度下降中自动涌现，而非人工搜索。** 打靶法虽然用了同样的物理信息，但需要人设计搜索区间（需要专门的理论公式）、选择积分方向（避开奇点）、选择求根算法。PINN只需要定义loss，$\alpha$ 自己跑出来。当然，对Guderley这个经典问题，打靶法的人工设计成本很低；但对更复杂的、没有现成理论指导的问题，PINN的"无需人工设计"优势会更加显著。

**我们不claim PINN精度超过打靶法**——对这个已被充分研究的经典问题，打靶法更快更准。我们的贡献在于: (1) 方法论 (2) 可扩展性 (3) 可迁移性。

## 5. 框架迁移: Taylor-Maccoll锥面绕流

### 5.1 为什么要做迁移？

消融实验证明了123框架在Guderley问题上每个组件的必要性。但一个自然的质疑是：**这套框架是不是只对Guderley这一个问题有效？**

如果123框架只是一个针对特定ODE的trick，那学术价值就很有限。我们需要证明它是一个**通用的方法论pattern**——在其他eigenvalue ODE问题上也能直接套用。

为此，我们选择了一个**物理上完全不同**的经典问题来验证。

### 5.2 Taylor-Maccoll问题

超音速气流绕锥体流动（如飞行器锥形头部）:

- **已知**: 来流Mach数 $M_\infty$，比热比 $\gamma$，半锥角 $\theta_c$
- **未知**: 激波角 $\beta$ (eigenvalue)
- **传统方法**: 同样是打靶法

### 5.3 框架迁移对照

**同一套123recipe，不同的物理**:

| 框架组件 | Guderley | Taylor-Maccoll |
|---------|----------|----------------|
| 原始方程 | 非定常Euler (球/柱对称) | 定常Euler (轴对称锥面) |
| **1. 化简** | → Chisnell 1阶ODE | → Taylor-Maccoll 2阶ODE |
| **2. 混合残差** | sonic点处 $D \to 0$ | sonic线处 $\tilde{c}^2 - v_\theta^2 \to 0$ |
| **3. 硬约束** | 两端value硬编码 | 一端value + 一端导数=0 |
| eigenvalue | $\alpha$ (自相似指数) | $\beta$ (激波角) |

### 5.4 结果

下图并列展示了Guderley(α收敛)和Taylor-Maccoll(β收敛)的训练过程——同一套框架，不同物理:

![框架迁移对比](self_discover/ablation/output/fig_framework_transfer.png)

4个Taylor-Maccoll测试案例的β收敛轨迹:

![Taylor-Maccoll β收敛轨迹](taylor_maccoll/output/fig_tm_beta_convergence.png)

| Case | $\beta_{\rm ref}$ (°) | $\beta_{\rm PINN}$ (°) | 误差 (%) |
|------|-----------|-----------|---------|
| M=2, $\theta_c$=20° | 37.796 | 37.966 | 0.45 |
| M=3, $\theta_c$=20° | 29.615 | 29.707 | 0.31 |
| M=2, $\theta_c$=30° | 48.079 | 48.460 | 0.79 |
| M=3, $\theta_c$=15° | 25.259 | 25.350 | 0.36 |

**4/4全部成功**。精度(0.3-0.8%)不如Guderley(~$10^{-6}$%)，原因:
- TM是**二阶**ODE (vs 一阶)，autograd误差累积更大
- 有**两个**可学习参数 ($\beta$, $v_{rc}$) vs 一个 ($\alpha$)
- 硬约束不如Guderley完美

**但核心结论成立: 同一套123框架recipe成功迁移到不同物理问题。**

## 6. 扩展性验证: PINN框架能做到、打靶法做不到的事

消融实验和框架迁移分别回答了"每个组件是否必要"和"框架是否通用"。但还有一个问题：**既然打靶法精度更高、速度更快，PINN框架的独特价值在哪？**

答案是**可扩展性**——PINN可以通过简单地修改loss函数来处理打靶法无法自然处理的场景。以下实验验证了这一点。

### 6.1 噪声鲁棒性 (48/48成功)

打靶法依赖精确ODE积分，**无法融合含噪观测数据**。PINN只需在loss中加一项:

$$L = L_{\rm ODE} + \lambda \cdot \text{MSE}(C_{\rm pred}, C_{\rm obs}^{\rm noisy})$$

实验: 4个噪声级别(0%, 1%, 5%, 10%) × 4个配置 × 3个随机种子 = **48次训练**

![噪声鲁棒性](self_discover/ablation/output/fig_noise_robustness.png)

- **48/48全部成功**
- 即使10%噪声，最大 $\alpha$ 误差仅**0.007%**
- ODE物理约束起到了天然的正则化/去噪作用

### 6.2 α+γ双参数反演 (4/4成功)

当 $\gamma$ 也未知时（打靶法需要完全重构为2D求根），PINN只需加一个 `nn.Parameter` 和一行数据loss:

![双参数反演](self_discover/ablation/output/fig_dual_param.png)

- 蓝线: $\alpha$ 的收敛轨迹，红线: $\gamma$ 的收敛轨迹
- 虚线标注 "γ unfrozen": 前5000 epoch冻结γ让网络稳定，之后放开联合优化
- γ=1.4的两个case和γ=5/3柱面收敛到正确值；γ=5/3球面的γ未完全收敛但α依然准确
- **打靶法在此场景下需要完全重构为多维求根，PINN只需两行改动**

### 6.3 扩展实验总结与论文定位

| 扩展实验 | 做了什么 | 结果 | 证明了什么 |
|---------|---------|------|---------|
| **Taylor-Maccoll迁移** | 123框架迁移到不同物理 | 4/4成功 | 框架**通用**，不限于Guderley |
| **噪声鲁棒性** | 含噪数据下α反演 | 48/48成功 | PINN能融合数据，打靶法不行 |
| α+γ双参数反演 | 两个参数同时未知 | 4/4成功 | PINN天然支持多参数 |
| 参数化PINN | 一次训练发现α(γ)曲线 | 成功 | PINN可输出参数函数 |
| 多几何统一 | 一个网络同时发现球面+柱面α | 成功但无额外gain | 物理太强，加项没被需要 |

**这些扩展实验共同回答一个问题**: 虽然打靶法在标准eigenvalue问题上精度更高，但PINN框架在**非标准场景**(含噪数据、多参数、不同物理)下展现出打靶法不具备的灵活性。

## 7. 终极验证: 跳过数学化简，直接从原始Euler方程发现α

### 7.1 一个尖锐的问题

前面所有实验（消融、迁移、噪声、双参数）都在1D ODE上进行。一个诚实的问题是：**在1D ODE上，真的需要神经网络吗？**

答案是：**不一定**。1D ODE的解是光滑的、低自由度的，多项式拟合 + `scipy.minimize` 大概率也能做到类似的效果（`canonical/nonpinn_fit.py` 就是这么做的）。PINN在1D ODE上的价值主要是方法论（消融揭示的设计原则），而非不可替代性。

那PINN真正不可替代的场景是什么？

### 7.2 直接求解2D Euler方程

我们跳过Chisnell的天才化简，直接用原始的球对称Euler方程：

$$\frac{\partial \rho}{\partial t} + \frac{\partial (\rho u)}{\partial r} + \frac{(n-1)\rho u}{r} = 0$$

$$\frac{\partial (\rho u)}{\partial t} + \frac{\partial (\rho u^2 + p)}{\partial r} + \frac{(n-1)\rho u^2}{r} = 0$$

$$\frac{\partial E}{\partial t} + \frac{\partial [(E+p)u]}{\partial r} + \frac{(n-1)(E+p)u}{r} = 0$$

网络输入 $(r, t)$，输出 $(\rho, u, p)$，激波轨迹 $R(t) = (1-t)^\alpha$，$\alpha$ 作为可训练参数。

这是一个2D输入、3个耦合非线性PDE、带移动激波边界的问题——多项式的维度灾难让它无法处理。

### 7.3 关键发现: 纯PDE无法确定α

| 实验 | α结果 | 误差 | 结论 |
|------|-------|------|------|
| 纯PDE（无观测数据） | 0.521 | 27.4% | 完全失败 |

**原因**: $\alpha$ 不是Euler方程本身的eigenvalue。原始PDE对**任意** $\alpha$ 都有解——网络可以对任何激波轨迹拟合出一个满足PDE的流场。只有在ODE化简后，通过音速点正则性条件，$\alpha$ 才被唯一确定。

这反过来说明了一件重要的事：**组件1（ODE化简）不仅仅是"降维加速"，它在编码eigenvalue的数学结构**。

### 7.4 PDE + 稀疏观测数据 → 成功

在激波面上加入少量观测点（模拟实验测量），PINN通过PDE-数据融合成功发现 $\alpha$：

| 配置 | $\alpha_{\rm PINN}$ | $\alpha_{\rm ref}$ | 误差 |
|------|---------------------|---------------------|------|
| $\gamma$=1.4, 球面 | 0.717086 | 0.717175 | 0.012% |
| $\gamma$=1.4, 柱面 | 0.835224 | 0.835323 | 0.012% |
| $\gamma$=5/3, 球面 | 0.688290 | 0.688377 | 0.013% |
| $\gamma$=5/3, 柱面 | 0.815517 | 0.815625 | 0.013% |

**4/4全部成功**，误差~0.01%。网络结构: 6层×128神经元，输入 $(r,t)$，输出 $(\rho,u,p)$，8000 epoch。

### 7.5 最少需要多少观测点？

| 观测点数 | $\alpha_{\rm PINN}$ | 误差 | 状态 |
|---------|---------------------|------|------|
| 30 | 0.717111 | 0.009% | OK |
| 10 | 0.717075 | 0.014% | OK |
| 5 | 0.717149 | 0.004% | OK |
| 3 | 0.716889 | 0.040% | OK |
| 2 | 0.716906 | 0.037% | OK |
| 1 | 0.712987 | 0.584% | 不稳定 |

**最少2个观测点**即可稳定发现 $\alpha$（误差<0.2%）。1个点不够稳定——因为1个 $(r,t)$ 点无法唯一确定幂律 $R(t)=(1-t)^\alpha$ 的指数。

### 7.6 这个实验的意义

| 方法 | 需要Chisnell化简？ | 需要观测数据？ | 能发现α？ |
|------|-------------------|---------------|----------|
| 打靶法 | 是 | 否 | 是（机器精度） |
| 1D ODE PINN (123) | 是 | 否 | 是（$10^{-6}$%） |
| 多项式拟合 | 是 | 否 | 是（也能做到） |
| **2D PDE PINN** | **否** | **是（≥2个点）** | **是（0.01%）** |
| 2D PDE 纯物理 | 否 | 否 | **否（α不唯一）** |

这张表清楚地展示了PINN的定位：

- 如果你有数学化简（Chisnell变换），打靶法最好，PINN和多项式都能做但没有不可替代性
- 如果你**没有**数学化简（现实中大多数问题），只有PINN能做PDE+数据融合来发现未知参数
- 2个观测点 + 原始PDE = 发现eigenvalue，这是多项式和打靶法都做不到的

代码: `self_discover/pinn_2d_euler.py`

## 8. 论文贡献总结

### 我们不claim什么

"PINN比打靶法更好"——对Guderley这个经典问题，打靶法更快更准。

### 我们claim什么

**Claim 1: 方法论 (消融实验)**

对ODE eigenvalue问题，PINN框架中哪些设计选择是必要的:
- ODE化简: 必要 (loss降5-6个量级)
- 混合残差: 必要 (唯一在所有条件下稳定的形式)
- 双端硬约束: 必要 (精度提升5个量级)
- warmup: 不需要 (硬约束已足够)

这些insight对其他ODE/PDE eigenvalue PINN问题有直接指导意义。

**Claim 2: 漏斗landscape**

发现loss vs α存在极窄极深的漏斗结构，解释了eigenvalue PINN对初始化敏感的根本原因。

**Claim 3: 可迁移可扩展框架**

- **可迁移**: 同一套123框架从Guderley迁移到Taylor-Maccoll，代码结构几乎不变
- **可扩展**: 天然支持多参数、含噪数据等打靶法难以处理的场景

**Claim 4: PINN在原始PDE上的不可替代性**

- 跳过所有数学化简，直接从2D Euler方程 + 2个观测点发现α（误差0.01%）
- 纯PDE无法确定α（误差27%），证明ODE化简编码了eigenvalue的数学结构
- 多项式无法处理2D输入 + 3耦合PDE + 移动边界，PINN是唯一可行的PDE-数据融合框架

### 论文叙事线

```
1. Guderley问题作为benchmark → 有精确解可验证
2. 打靶法作为baseline → 诚实对比，承认其精度优势
3. 核心贡献 = 消融实验 → 系统揭示123框架每个组件的必要性
4. 漏斗landscape → 理论insight
5. Taylor-Maccoll迁移 → 证明框架通用性
6. 扩展验证 → 噪声鲁棒性、双参数反演等
7. 终极验证 → 跳过化简，2D Euler + 稀疏数据发现α，证明PINN不可替代性
```

## 10. 参数化PINN扩展（新工作）

### 10.1 动机

前面所有实验（消融、迁移、噪声、双参数）都是**case-by-case**的：固定 $\gamma$ 和几何形状，训练一个模型，得到一个 $\alpha$。如果想知道不同 $\gamma$ 下的 $\alpha(\gamma)$ 曲线，需要重复训练多次。

**新问题**：能否训练一次，得到整条 $\alpha(\gamma)$ 曲线？即把 $\gamma$ 作为网络输入，输出对应的 $\alpha$。

### 10.2 参数化PINN：γ作为输入

**核心思路**：在123框架基础上，增加一个小网络 `alpha_net(γ) → α`，同时把 $\gamma$ 也输入给 `C_net`。

**网络结构**：

```
alpha_net: γ (1D) → [Linear(1,32), Tanh, Linear(32,32), Tanh, Linear(32,1)] → α ∈ (0.5, 1.0)
C_net:     (s, γ) (2D) → [4层×64神经元, Tanh] → 修正量
```

硬约束结构不变：

$$C(s; \gamma) = (1-s) \cdot C_s(\alpha(\gamma), \gamma) + s \cdot C_0(\alpha(\gamma), \gamma) + s(1-s) \cdot \text{C\_net}(s, \gamma)$$

**训练方式**：每个batch随机采样 $B=32$ 个 $\gamma \in [1.2, 2.0]$，每个 $\gamma$ 配200个配点，共 $32 \times 200 = 6400$ 个残差点。

**预训练**：用打靶法计算16个参考点 $(\gamma_i, \alpha_i)$，先单独训练 `alpha_net` 3000 epoch，使其初始化接近真值。

**结果**（`pinn_parametric.py`，γ∈[1.2, 2.0]，10000 epoch）：

| 几何 | Max误差 | Mean误差 |
|------|---------|---------|
| 球面 (n=3) | 0.05% | 0.015% |
| 柱面 (n=2) | 0.06% | 0.005% |

与case-by-case（精度~$10^{-6}$%）相比，参数化版本精度略低，但**一次训练覆盖整个 $\gamma$ 范围**，可连续查询任意 $\gamma$。

### 10.3 统一参数化PINN：γ和n同时作为输入

进一步，将几何形状 $n \in \{2, 3\}$ 也作为网络输入，一个网络同时覆盖球面和柱面。

**网络结构**：

```
alpha_net: (γ, n) (2D) → α ∈ (0.5, 1.0)
C_net:     (s, γ, n) (3D) → 修正量
```

训练时每个batch随机混合 $n \in \{2, 3\}$ 和 $\gamma \in [1.2, 2.0]$。

**结果**（`pinn_parametric_unified.py`）：

| 几何 | Max误差 | Mean误差 |
|------|---------|---------|
| 球面 (n=3) | 0.38% | 0.04% |
| 柱面 (n=2) | 0.10% | 0.015% |

统一版精度略低于分开训练，因为一个网络需要同时学习两种不同的物理结构。

### 10.4 三种方案对比

| 方案 | 输入 | 训练次数 | 球面Max误差 | 柱面Max误差 |
|------|------|---------|-----------|-----------|
| Case-by-case (原始123) | s | 每个(γ,n)一次 | ~$10^{-6}$% | ~$10^{-6}$% |
| 参数化γ (`pinn_parametric.py`) | (s, γ) | 每种几何一次 | 0.05% | 0.06% |
| 统一γ+n (`pinn_parametric_unified.py`) | (s, γ, n) | 一次 | 0.38% | 0.10% |

**精度 vs 灵活性的trade-off**：训练次数越少，覆盖范围越广，但精度略有下降。对于需要扫描大量 $\gamma$ 值的场景（如绘制 $\alpha(\gamma)$ 曲线），参数化版本更高效。

### 10.5 Best-of-N训练策略

由于参数化PINN的优化landscape存在局部最优，不同随机种子的训练结果有差异。实践中可用 `--n-runs N` 参数独立训练N次，自动保留验证误差最小的模型：

```bash
python pinn_parametric.py --n-runs 5 --device cuda
```
